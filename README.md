# Sales-Analysis-PowerBI
# لوحة تحليل المبيعات باستخدام Power BI

## نبذة عن المشروع

مشروع لتحليل بيانات المبيعات بهدف فهم أداء المبيعات والأرباح، وتحليل المنتجات والعملاء والفترات الزمنية واستخراج أهم المؤشرات والنتائج من البيانات.

## الأدوات المستخدمة

* Microsoft Excel
* Power Query
* Power BI
* DAX

## خطوات العمل

* تنظيف البيانات ومعالجة القيم الفارغة.
* تجهيز وتحويل البيانات باستخدام Power Query.
* إنشاء العلاقات بين الجداول.
* إنشاء Measures باستخدام DAX.
* حساب إجمالي المبيعات والأرباح ومتوسطات الأداء.
* تحليل أداء المنتجات حسب المبيعات والأرباح.
* تحليل المبيعات والأرباح حسب الشهور.
* إنشاء Dashboard تفاعلية باستخدام Power BI.

## أهم النتائج

* اكتشاف وجود بعض المنتجات التي تحقق مبيعات ولكن بهامش ربح منخفض.
* ارتفاع المبيعات بشكل ملحوظ خلال شهري فبراير ويوليو.
* تحديد المنتجات الأعلى تحقيقًا للأرباح، ومنها Laptop وCabinet وStapler.
* استخدام البيانات لاستخراج مؤشرات تساعد على فهم أداء المنتجات والمبيعات.

## الهدف من المشروع

تطبيق مهارات تحليل البيانات عمليًا وتحويل البيانات الخام إلى معلومات ومؤشرات تساعد في فهم أداء المبيعات واتخاذ قرارات أفضل.
